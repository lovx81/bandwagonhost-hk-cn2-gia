4GB 内存通常比 2GB 更从容。不过，实际能承载多少访问量仍取决于程序、数据库查询、缓存策略和图片文件大小，不能仅根据 vCPU 数量直接推断网站并发能力。

## 购买前需要注意的限制

### 这是自管理服务器

BandwagonHost 官方明确将服务描述为 self-managed。你需要自己处理：

- SSH 密钥和登录安全
- 系统更新
- 防火墙规则
- Web 服务和数据库安装
- SSL 证书
- 恶意登录防护
- 应用备份
- 日志和磁盘空间管理

如果服务器用于正式业务，建议开通后先完成基础安全配置，再部署网站。至少要关闭不必要端口、禁用密码登录或限制 SSH 来源，并确认备份确实能够恢复。

### 备份和快照不能替代完整灾备

官方套餐页面列出自动备份和快照功能，但这不意味着所有业务数据都已经满足灾备要求。网站文件、数据库、对象存储和配置文件最好保留一份独立于服务器的备份。尤其是数据库，不能只依赖某个时间点快照来解决误删或数据损坏问题。

### 机房和价格要在结账页再次确认

BandwagonHost 的产品页面按地区和产品系列区分，页面价格也可能因计费周期、促销版本或库存变化而调整。当前香港 CN2 GIA 页面显示的是 40G 到 1280G 六档配置，但下单时仍应检查：

1. 地区是否为 Hong Kong Equinix HK2。
2. 套餐名称是否为 Hong Kong CN2 GIA VPS。
3. 计费周期是否选对。
4. 月流量和存储空间是否符合需求。
5. 最终订单金额是否包含税费或其他结算项目。
